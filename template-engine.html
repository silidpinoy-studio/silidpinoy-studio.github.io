Template Engine

Zero-tag .docx / .xlsx filling. Upload your school's blank template, enter data, download a completed document that preserves logos, seals, margins, fonts, and table layout.

Phase 1 — Ingest

Upload your school's blank .docx. The engine reads the ZIP, unpacks word/document.xml, and scans for placeholders.

Phase 2 — Analyze

Detects template category (ILAW, TOS, DLL) and finds placeholder slots {{key}} in the XML.

Awaiting file + analyze

Phase 4 — Fill & Export

Enter data or use AI output. The engine injects into the correct XML cells, preserving all formatting, then delivers the .docx.

How It Works

Slot Detection (Phase 2)

Reads word/document.xml via DOMParser, finds w:t nodes with {{tag}} content. Each slot maps to exactly one cell.

In-Place Injection (Phase 4)

Writes data into only the matched text node — parent w:r styles (font/colors/bold), images, headers, footers, signatures preserved. No conversion to HTML.

Pipeline: Ingest (JSZip) → Analyze (DOMParser / slot binder) → Generate (AI / JSON) → Inject (OpenXML AST mutation) → Export (JSZip repackage + download). Image generation excluded.
Integrated with SilidPinoy Studio • Uses shared-api / SilidKeys • No image generation • Sandbox verified (isolated build)
